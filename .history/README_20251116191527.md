# Chess Game Analysis Dashboard

## Overview

This project provides an interactive Streamlit-based dashboard for analysing chess games from Chess.com. It offers on-demand retrieval of user games, performance analysis, opening insights, and a modular machine learning component to support further exploration. The system is designed to be lightweight, easy to deploy, and accessible to users without technical guidance.

A live version of the application is available here:

**[Streamlit Application Link](<insert-link-here>)**

The dashboard accepts **any Chess.com username**, retrieves available games for that player, and performs analysis directly in-app.

---

## Features

### On-Demand Game Retrieval
- Users enter a Chess.com username and optional time window.
- The system fetches all available games using the Chess.com public API.
- Newly fetched games are merged into a local dataset stored on the server.
- Data is stored in simple CSV format for transparency and low overhead.

### Performance Analysis
- Summary statistics for wins, losses, draws.
- Trends against higher- and lower-rated opponents.
- Visualisation of game outcomes over time.
- Aggregated opening usage and success metrics.

### Opening Classifier (Modular ML Feature)
- A standalone Random Forest classifier predicts expected performance for each opening.
- Inputs may include opening name, ECO code, player rating, opponent rating, and game metadata.
- Outputs probability estimates for favourable outcomes.
- Fully modular: the ML component can be added or removed without affecting the dashboard.

### Game Exploration
- Interactive game table with filters.
- Each game includes a direct link to the full record on Chess.com.
- Optional PNG display if game images are retrieved.
- Supports quick inspection without implementing a full chessboard viewer.

### Dashboard Interface
- Built with **Streamlit** for rapid prototyping and end-user accessibility.
- Clear sections for data ingestion, metrics, classifier results, and game browsing.
- Designed to allow future expansion with minimal refactoring.

# Chess Game Analysis Dashboard

A lightweight, interactive Streamlit application for analyzing your Chess.com games with performance metrics and ML-powered win probability predictions.

## Features

- **on demandl Game Fetching based on username**: Pull games directly from Chess.com API
- **Performance Analytics**: Win rates, rating trends, opening analysis
- **Opponent Analysis**: Performance against different rating levels
- **ML Predictions**: Logistic regression model for win probability estimation
- **Interactive Visualizations**: Charts and graphs using Plotly
- **Game Access**: Direct links to review individual games on Chess.com

## Project Structure

```
chess_dashboard/
├── app.py                 # Main Streamlit dashboard
├── data_fetcher.py       # Chess.com API integration
├── analyzer.py           # Game statistics and metrics
├── predictor.py          # ML prediction model
├── requirements.txt      # Python dependencies
├── data/                 # Stored game data (CSV)
└── models/               # Trained ML models
```

## Usage

### Step 1: Fetch Your Games
1. Enter a Chess.com username in the sidebar
2. Select a time period (last month, 3 months, 6 months, or custom)
3. Click "Fetch Games" to download your game history

### Step 2: Explore Analytics
- **Performance Overview**: Total games, win rate, average ratings
- **Rating Trend**: Track your rating progression over time
- **Results Over Time**: Weekly win/loss/draw patterns
- **Opening Performance**: Analyze your most-played openings
- **Opponent Strength**: Performance against higher/lower rated players

### Step 3: Use Predictions
- Train the ML model on your historical games (requires 20+ games)
- Input your rating, opponent rating, and color
- Get win probability predictions
- View probability curves across opponent rating ranges

### Step 4: Review Individual Games
- Browse recent games in the interactive table
- 
- Click "View Game" links to analyze specific games on Chess.com

## Data Storage

- Games are saved as CSV files in the `data/` directory
- File naming: `{username}_games.csv`
- Click "Download Data" to download the csv
- similar for any results

## Technical Details

### Data Fetcher (`data_fetcher.py`)
- Uses Chess.com public API
- Parses PGN data to extract opening information
- Handles multiple months of game history
- Rate-limited requests to respect API limits

### Analyzer (`analyzer.py`)
- Computes overall statistics (win rate, rating averages)
- Generates time-series trends
- Analyzes performance by opening, color, time control
- Prepares features for ML model

### Predictor (`predictor.py`)
- Random Forest & Logistic regression classifier
- Features: user rating, opponent rating, rating difference, color
- Provides probability estimates for win/loss outcomes
- Generates probability curves across rating ranges

### Dashboard (`app.py`)
- Streamlit interface with sidebar navigation
- Interactive Plotly charts
- Session state management for data persistence
- Responsive layout with columns and tabs

## API Information

This dashboard uses the **Chess.com Public API**:
- No API key required
- Rate limits apply (be respectful with requests)
- Documentation: https://www.chess.com/news/view/published-data-api

## Limitations

- Only supports Chess.com
- Requires internet connection for initial data fetch
- ML model accuracy depends on game history volume

## Troubleshooting

**"No games found"**: Check username spelling and ensure you have played games in the selected period

**"Model training error"**: You need at least 20 games for reliable ML predictions

**"API timeout"**: Chess.com API may be slow or rate-limiting; try again in a few minutes

**"Module not found"**: Ensure all dependencies are installed with `pip install -r requirements.txt`
