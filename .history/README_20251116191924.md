# Chess Game Analysis Dashboard

An interactive Streamlit-based dashboard for analyzing chess games from Chess.com. This lightweight application provides on-demand game retrieval, performance analysis, opening insights, and machine learning-powered predictions—all accessible without technical expertise.

**[Live Application](<insert-link-here>)**

The dashboard accepts **any Chess.com username**, retrieves available games for that player, and performs comprehensive analysis directly in-app.

---

## Features

### On-Demand Game Retrieval
- Enter any Chess.com username and optional time window
- Fetch all available games using the Chess.com public API
- Newly retrieved games are merged into a local dataset stored on the server
- Data stored in simple CSV format for transparency and low overhead
- No API key required

### Performance Analytics
- **Summary Statistics**: Win/loss/draw ratios and overall performance metrics
- **Rating Trends**: Track rating progression over time
- **Opponent Analysis**: Performance against higher-rated, lower-rated, and similar-rated opponents
- **Opening Performance**: Analyze your most-played openings and their success rates
- **Time Control Analysis**: Compare performance across different time formats
- **Color Performance**: White vs Black win rate comparison
- **Results Over Time**: Weekly patterns in game outcomes

### Machine Learning Predictions
- **Logistic Regression Classifier**: Predicts win probability based on ratings and color
- **Random Forest Classifier**: Advanced opening-based performance predictions
- **Features**: Player rating, opponent rating, rating difference, color, opening patterns
- **Probability Curves**: Visualize expected performance across opponent rating ranges
- **Model Training**: Automatic training on your historical games (requires 20+ games)
- **Modular Design**: ML components can be added or removed without affecting core functionality

### Game Exploration
- Interactive game table with filtering capabilities
- Direct links to full game records on Chess.com
- Review recent games with detailed metadata
- Quick inspection without implementing a full chessboard viewer
- Optional PNG display if game images are retrieved

### Dashboard Interface
- Built with **Streamlit** for rapid prototyping and user accessibility
- Interactive Plotly visualizations
- Clear sections for data ingestion, metrics, predictions, and game browsing
- Session state management for data persistence
- Responsive layout with columns and tabs
- Designed for future expansion with minimal refactoring

## Installation

### Option 1: Using pip

1. **Clone or download this project**

2. **Install dependencies**:
```bash
pip install -r requirements.txt
```

3. **Run the dashboard**:
```bash
streamlit run app.py
```

### Option 2: Using uv

1. **Install uv** (if not already installed):
```bash
pip install uv
```

2. **Install project dependencies**:
```bash
uv sync
```

3. **Launch the dashboard**:
```bash
uv run streamlit run app.py
```

## Usage Guide

### Step 1: Fetch Games
1. Enter a Chess.com username in the sidebar
2. Select a time period:
   - Last Month
   - Last 3 Months
   - Last 6 Months
   - Custom Date Range
3. Click **"Fetch Games"** to download game history
4. Or click **"Load Saved Data"** to reload previously fetched games

### Step 2: Explore Analytics
Navigate through the interactive dashboard tabs:

- **Performance Overview**: Total games, win rate, average ratings
- **Rating Trend**: Visualize rating progression over time
- **Results Over Time**: Weekly win/loss/draw patterns
- **Opening Performance**: Analyze your opening repertoire
- **Opponent Strength**: Performance breakdown by opponent rating category
- **Color Analysis**: White vs Black performance comparison
- **Time Control Stats**: Performance across different game formats

### Step 3: Use ML Predictions
- Automatic model training on your historical games (minimum 20 games required)
- Input your rating, opponent rating, and color choice
- Get win probability predictions with confidence metrics
- View probability curves across opponent rating ranges
- Understand model accuracy with training/test performance metrics

### Step 4: Review Individual Games
- Browse recent games in the interactive table
- Click **"View Game"** links to analyze specific games on Chess.com
- Filter and sort games by date, opponent, rating, result, or opening

### Step 5: Download Data
- Export your game data as CSV files from the `data/` directory
- Download analysis results and visualizations
- Save trained ML models for future use

## Technical Details

### Data Fetcher (`data_fetcher.py`)
- Chess.com public API integration
- PGN parsing to extract opening information, ECO codes, and metadata
- Multi-month game history retrieval with automatic pagination
- Rate-limited requests to respect API constraints
- Incremental data updates and deduplication
- Local CSV storage with flexible file naming

### Analyzer (`analyzer.py`)
- Comprehensive statistical computations (win rates, rating averages)
- Time-series trend generation and analysis
- Performance segmentation by opening, color, time control, and opponent strength
- Feature engineering for ML model input
- Data aggregation and grouping utilities
- Historical pattern detection

### Predictor (`predictor.py`)
- **Logistic Regression**: Binary win/loss classification
- **Random Forest** (optional): Advanced multi-class prediction with opening features
- Feature set: user rating, opponent rating, rating difference, color, opening patterns
- Probability estimates for game outcomes
- Model persistence (save/load functionality)
- Feature importance analysis
- Cross-validation and performance metrics
- Probability curve generation across rating ranges

### Dashboard (`app.py`)
- Streamlit-based user interface
- Interactive Plotly charts and visualizations
- Session state management for seamless user experience
- Sidebar navigation for data management
- Responsive multi-column and tabbed layouts
- Real-time model training and prediction
- Error handling and user feedback

## Troubleshooting

**"No games found"**
- Verify Chess.com username spelling
- Ensure games exist in the selected time period
- Check that the username has public games available

**"Model training error"**
- Minimum 20 games required for reliable ML predictions
- Ensure sufficient data variety (wins, losses, different opponents)

**"API timeout"**
- Chess.com API may be experiencing high traffic
- Wait a few minutes and retry
- Check your internet connection

**"Module not found"**
- Install all dependencies: `pip install -r requirements.txt`
- Or use uv: `uv sync`
- Verify Python version compatibility (3.8+)

**"CSV file corrupted"**
- Delete the CSV file in `data/` directory
- Re-fetch games from Chess.com
