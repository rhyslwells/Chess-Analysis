# Chess Game Analysis Dashboard

## Overview

**Chess Game Analysis Dashboard** is an interactive, Streamlit-based analytics application for exploring and evaluating chess games from Chess.com. It enables on-demand game retrieval, structured performance analysis, opening insights, and lightweight machine learning predictions through a single, browser-based interface.

The dashboard accepts **any Chess.com username**, retrieves publicly available game data, and performs all analysis locally without requiring API keys or prior technical setup.

## Features

♟️ **Game Ingestion**

* On-demand retrieval of games via the Chess.com public API
* Username-based lookup with optional date range filtering
* Incremental ingestion with merge into a local dataset
* Simple CSV-based storage for transparency and portability
* No authentication or API key required

📊 **Performance Analytics**

* Summary metrics: wins, losses, draws, and win rates
* Rating progression over time
* Opponent strength analysis (higher-, lower-, and similarly-rated)
* Opening frequency and performance breakdown
* Time control performance comparison
* Color-based analysis (White vs Black)
* Weekly and temporal result trends

🤖 **Machine Learning Insights**

* Logistic regression classifier trained on historical games
* Win probability estimation using ratings and color
* Probability curves across opponent rating ranges
* Model diagnostics including train/test performance
* Automatic retraining once sufficient data is available (minimum 20 games)

🔍 **Game Exploration**

* Interactive, filterable game table
* Direct links to full game records on Chess.com
* Detailed per-game metadata inspection
* Lightweight review workflow without embedded board analysis
* Optional PNG rendering when game images are available

🖥️ **Dashboard Interface**

* Built with **Streamlit** for accessibility and rapid iteration
* Interactive Plotly visualizations
* Clear separation of ingestion, analytics, predictions, and browsing workflows

## Limitations

⚠️ **Current Constraints**

* Relies on Chess.com public data availability and rate limits
* No real-time updates; games must be fetched manually

## Getting Started

### Prerequisites

* Python 3.10+
* Internet access to Chess.com public endpoints

### Installation (using uv)

1. Install **uv**:

```bash
pip install uv
```

2. Install dependencies:

```bash
uv sync
```

3. Launch the dashboard:

```bash
uv run streamlit run app.py
```

## API Information

This project uses the **Chess.com Published Data API**:

* Public access only (no authentication)
* Subject to Chess.com rate limiting policies
* Endpoints include player profiles, game archives, and monthly listings
* Documentation: [https://www.chess.com/news/view/published-data-api](https://www.chess.com/news/view/published-data-api)
